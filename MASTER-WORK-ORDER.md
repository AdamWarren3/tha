## Floating — stated but never filed anywhere

**This section is the point of this document.** Items here exist only in conversation and are the most likely to be lost.

- **Whether the affirmative case survives ADR-008's narrowing.** The dream machine, burial and scheduled return are out of scope unsupervised. Whether the supervised version is worth building has not been decided.
- **Neither projection nor measurement.** What a model returns is conditioned on the user's own material, so it is not projection — but it is generated rather than computed, so it is not measurement. The middle position has no name, and that is why several naming attempts have failed.
- **The stance claim.** Companion, tool, mirror, oracle — four postures, one machine, and the proposal that posture predicts outcome. `investigations/Stance and Sustained Rapport in Extended AI Interaction.md` §1, unchecked.
- **The Protocol run unaided and run with machine-supplied material are two objects, and the corpus has one document for both.** Opened 2026-08-08 when `The Consent Layer` §4c gained its scope paragraph. → `CLAIM-LEDGER.md`
- **The universal calculator.** If a calculation entered into a shared instrument updates it for everyone using it, that is a butterfly effect with no precedent. Parked by the author 2026-08-16, explicitly not to be researched yet. Adjacent notes already in the corpus: RLHF, RLAiF, The Collective Layer, The Butterfly Effect as Practice. **Before anything is built on it: whether that loop closes is an empirical question with a specific answer, and it varies by product and setting.**
